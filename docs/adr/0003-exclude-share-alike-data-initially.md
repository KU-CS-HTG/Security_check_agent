# ADR-0003: 동일조건공유(CC-BY-SA) 데이터는 초기 수집에서 제외

- 상태: 승인(2026-10-09)
- 맥락: OSV가 Ubuntu 보안 데이터를 CC-BY-SA 4.0으로 표기한다(Ubuntu 공식 문서로는 미확인). 동일조건공유는 가공물을 공유할 때 같은 조건을 요구하므로, 공개 포트폴리오(평가셋, 시각화, 데모)와 충돌할 수 있다.
- 결정(A안): 초기에는 Ubuntu 유래 데이터를 수집하지 않는다. `config/sources.yaml` 허용 목록에 넣지 않고, OSV 사용 시에도 Ubuntu 생태계 레코드를 거른다.
- 설계 요구(나중에 B안으로 올리기 위한 전제): raw/core 스키마의 모든 레코드에 `source_url`, `license`(SPDX 식별자 또는 공공누리 유형)를 저장한다.
- 승격 조건(B안: 수집하되 격리): ① Ubuntu 보안 데이터의 공식 라이선스를 문서로 확인, ② 공개 저장소·평가셋·스크린샷에서 Ubuntu 유래 내용을 분리할 수 있는 필터가 있을 것.
- 감수하는 손실: 배포판 백포트로 인한 `FIXED_IN`(배포판별 수정 버전) 근거가 약해져 리눅스 서버 관련 질문의 정확도가 낮을 수 있다. Phase 5 평가에서 이 한계를 실패 사례로 기록한다.

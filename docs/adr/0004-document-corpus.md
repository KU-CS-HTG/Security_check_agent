# ADR-0004: 문서 코퍼스는 A+C (PostgreSQL 문서 먼저, KISA 가이드는 허락 확인 후)

- 상태: 승인(2026-10-13)
- 맥락: 점검 항목(`CheckItem`)·조항(`Clause`)·지침(`Guideline`)을 만들 원문 문서가 필요하다.
  KISA "주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드"(2025-12-24, PDF 873쪽, 로그인 불필요, 텍스트 선택 가능,
  Unix 서버·DBMS·웹서버 장, DBMS 장에 PostgreSQL 없음)는 **공공누리 제4유형**(출처표시+상업적 이용금지+변경금지)이다.
  현행 정책(비상업 한정 안 함, ADR/SOURCES 결정 기록)에서는 제4유형을 수집하지 않는다.
- 결정:
  - **A**: PostgreSQL 공식 문서(`https://www.postgresql.org/docs/<버전>/`, PostgreSQL License, 승인 완료)로 문서 파이프라인(수집·파싱·조항 분할·추출·검수)을 먼저 완성한다.
  - **C**: KISA 가이드는 **수집하지 않고**, 이용 허락 가능 여부를 KISA에 문의한다(초안: `docs/sources/kisa-inquiry-draft.md`).
- KISA 승인 시 처리: 허락 또는 정책 변경(비상업 한정)이 확정되면 같은 파이프라인에 투입한다. 구조가 규칙적(장 → 분류 → 항목표: 항목명·중요도 상/중/하·코드 U-01…)이므로 규칙 기반 파서를 쓴다.
  변경금지 조건 때문에 **원문 그대로만 저장·인용**하고 LLM 요약·재서술 결과는 저장하지 않는다.
- 결과: 한국 공공기관 지침과의 연결은 승인 전까지 없다. 승인되지 않으면 한계로 문서화한다.

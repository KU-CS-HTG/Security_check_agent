# ADR-0005: 로컬 LLM은 Qwen2.5-7B-Instruct (Ollama)로 시작

- 상태: 승인(2026-10-13), 실측 후 재검토
- 맥락: 추출 단계는 망분리 가정상 외부 API 없이 동작해야 한다. 환경은 RTX 4070 Laptop(VRAM 8GB), 비상업 한정을 하지 않기로 했다.
- 결정: `qwen2.5:7b-instruct`(4비트 양자화, 약 4.7GB)를 Ollama로 실행한다(`config/models.yaml`, 기본 `http://localhost:11434`).
  이유: Apache-2.0(상업 이용 가능), JSON 출력 안정성, 영어·한국어 균형, 8GB VRAM에 여유.
- 제외한 후보: EXAONE 3.5(비상업 연구용 라이선스, 정책과 충돌), Llama 3.1 8B(한국어 약함), Gemma 2 9B(8GB에서 컨텍스트 제약).
- 안전장치: 출력은 JSON 스키마로 강제하고 pydantic으로 다시 검증한다. 모든 추출 항목은 원문 근거 문장을 포함하며, 근거가 원문에
  실제로 존재하는지 코드가 검증한다(없으면 재시도/폐기). temperature 0.
- 재검토 조건: 근거 검증 통과율 또는 사람 검수 승인율이 목표(2.5에서 정함)에 못 미칠 때 → 더 큰 모델(양자화 낮춤/CPU 오프로딩) 또는 프롬프트 개선.
- 미확인: Ollama의 JSON 스키마 강제 출력 지원 버전과 모델 태그는 설치 후 `ollama list`로 확인한다(2.3에서 검증).

# ADR-0006: 규칙 기반 우선, LLM은 자연어에만

- 상태: 승인(2026-10-13)
- 결정:
  | 데이터 | 방식 |
  |---|---|
  | OSV 레코드(JSON) | 규칙 기반 정규화(LLM 없음) |
  | PostgreSQL 보안 HTML | HTML 파서(LLM 없음) |
  | 문서(조항 단위 텍스트) | 조항 분할 후 LLM 추출 + 근거 검증 + 사람 검수 |
  | 구조가 규칙적인 문서(예: KISA 항목표) | 규칙 기반 파서, LLM은 검증·분류에만 |
- 이유: 구조가 있는 데이터를 LLM에 맡기면 느리고 틀릴 수 있다. 8GB VRAM의 7B 모델은 처리량이 제한적이다.
  규칙 기반은 재현 가능하고 테스트하기 쉽다.
- 품질 지표: ① 스키마 통과율, ② 재시도율, ③ 근거 문장 검증 통과율, ④ 사람 검수 승인율(샘플). 2.4~2.5에서 측정해 문서화한다.
- 위험도: 문서에 명시된 값만 사용한다. 없으면 LLM 추정값에 `risk_source=llm_inferred`를 붙여 구분한다. 취약점 심각도는 CVSS에서 규칙으로 산출한다.
